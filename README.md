# Siemsup.ru

Демонстрационная статическая версия сайта.

## Открыть сайт

https://bitaxa-72.github.io/Siemsup.ru/

## Локальная разработка

```powershell
npm.cmd install
npm.cmd run dev
```

## Сборка для GitHub Pages

```powershell
npm.cmd run build:pages
```

GitHub Actions публикует `dist` после каждого push в ветку `main`.
